# Figure 4 scripts

Scripts for treatment-associated malignant-cell plasticity, joint untreated-versus-treated trajectories, regimen-specific trajectory comparisons, and response-associated developmental remodeling.

Recommended run order:
1. `01_analyze_joint_treated_vs_untreated_monocle_trajectory.R`
2. `02_analyze_treatment_regimen_specific_monocle_trajectories.R`
3. `03_analyze_treatment_response_developmental_plasticity.R`

These scripts use Monocle3 and Seurat objects with treatment, regimen, response, sample, and malignant-cell-state annotations.
