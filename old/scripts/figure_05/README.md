# Figure 5 scripts

Scripts for Wilms tumor microenvironment analysis, including lymphoid, myeloid, and vascular compartments.

Recommended run order:
1. `01_plot_tme_lymphoid_myeloid_vasculature_composition.R`
2. `02_plot_tme_subtype_marker_dotplots.R`

The marker dot-plot script assumes processed compartment-specific Seurat objects for lymphoid, myeloid, and vasculature populations.
